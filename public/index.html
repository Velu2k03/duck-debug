Duck Debug

Stuck on an error? Quack it out with the duck.

Hi! I'm Duck. Paste your broken code and the error message, and I'll explain what went wrong in plain language.

The duck needs a brain

Duck Debug answers with Google's Gemini API. It's free to start:

  1. Get a free API key at Google AI Studio.
  2. Copy .env.example to .env and paste your key after GEMINI_API_KEY=.
  3. Restart the server with npm start.

Built for the Devpost "Build With AI: Basics" hackathon.
